Loading back into your ILS

    

      
Load the changed-records file with an overlay profile that matches on the field holding your record key. In this file that is usually 001.

      
Make sure your load profile protects local 520, 490 and 830 fields from being wiped by a later OCLC overlay.

      
Open the .mrk in MarcEdit and run Validate before loading if you want a second check.
